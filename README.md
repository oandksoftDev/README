# O&K softDev

We are a small web & mobile studio from Żory, Poland, run by Kuba and Oliwia.
We design and build websites, web apps and mobile apps from scratch, without templates or page builders.

### What we do
- **Websites** for businesses, with a headless CMS so clients edit content on their own
- **Web apps** with payments, bookings and third-party API integrations
- **Mobile apps** for iOS and Android
- **SEO, analytics and visual identity** to help our clients get found and remembered

### Tech stack
Next.js · React · TypeScript · Flutter · React Native · Sanity CMS · Supabase · SCSS · Vercel

### Selected work
- [FerroFrame](https://ferroframe.pl): B2B product platform for an urban furniture manufacturer
- [ZHIT](https://zhit.pl): product catalog for a building materials supplier
- [The Angels Apartments](https://angelsapartments.com): serviced apartments in Kraków's Old Town
- [Kancelaria Prawna Kapała](https://kancelariaprawna-kapala.pl): bilingual law firm website
- **CEV Scoreboard**: real-time beach volleyball scoring app for CEV Beach Pro Tour events
